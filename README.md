# ADS-B Flight Tracker

Feature-rich live ADS-B tracker for GitHub Pages and Windows.

- Live aircraft map using ADSB.lol
- Aircraft search and detail panel
- Altitude, speed, heading, vertical rate and squawk
- Aircraft photos and route metadata
- Worldwide airport search and selection
- Session track trails and replay
- Responsive web UI
- Automatic Windows NSIS installer and portable EXE through GitHub Actions

This is an independent implementation inspired by common flight-tracking features. It does not copy FlightRadar24 source code, proprietary assets, branding or UI.

Data sources: ADSB.lol, ADSBdb, OurAirports, Planespotters and OpenStreetMap.
